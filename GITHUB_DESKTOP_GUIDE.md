# GitHub Desktop - Step by Step Guide

## Step 1: Open GitHub Desktop
- Click the GitHub Desktop app icon on your taskbar or start menu
- You should see your BECA-Assessment project listed on the left

## Step 2: Click on "BECA-Assessment" in the left panel
- Current Repository should show: **BECA-Assessment**
- Current Branch should show: **main**

## Step 3: Click the "Changes" tab
- At the top you'll see two tabs: **Changes** | History
- Click **Changes** tab
- You should see files listed (index.html, js/app.js)

## Step 4: See the file changes
The screen shows:
```
Changes (2)
  ✓ index.html
  ✓ js/app.js
```

Each file is checked (✓) - this means it will be included in the commit.

## Step 5: Add a commit message
At the bottom left, you'll see a text box:
- **Summary (required):** type: `Fix: Add id='page' element for render functions`
- **Description:** Leave blank (optional)

## Step 6: Commit
Click the blue button: **"Commit to main"**
- Wait 2-3 seconds
- The button should say "Push origin" after

## Step 7: Push to GitHub
Click the blue **"Push origin"** button
- You'll see "Pushing to origin..." 
- Wait for it to finish (should say "Fetch origin" when done)

## Step 8: Wait for Netlify to Deploy
- Wait **2 minutes** for Netlify to auto-deploy
- Don't close GitHub Desktop

## Step 9: Refresh Your Browser
- Go to becaskill-assessment.netlify.app
- Press **Ctrl + Shift + Delete** to clear cache
- Press **Ctrl + R** to refresh
- The page should load without errors now! ✅

---

## If You Can't See Changes in GitHub Desktop

1. Make sure you're in the right repository (BECA-Assessment)
2. Make sure you're on the "main" branch
3. Make sure you clicked the "Changes" tab (not History)
4. If still nothing shows:
   - Close GitHub Desktop completely
   - Open it again
   - Select BECA-Assessment
   - Click Changes tab
   - The files should appear
