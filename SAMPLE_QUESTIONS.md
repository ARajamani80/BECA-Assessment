## ✅ QUESTION 1: MCQ (Multiple Choice)

**Type:** MCQ - Multiple Choice Question  
**Points:** 10  
**Module:** Basic Commands  

**Question Text:**
```
Which command opens the file dialog in AutoCAD to open an existing drawing?
```

**Options:**
- A) OPEN
- B) NEW
- C) SAVE
- D) EXIT
- E) IMPORT

**Correct Answer:** A) OPEN

**Explanation:**
The OPEN command is used to open existing drawing files in AutoCAD. The NEW command creates a new drawing, and SAVE saves the current work.

## ✅ QUESTION 2: TRUE/FALSE

**Type:** T/F - True/False  
**Points:** 5  
**Module:** Basic Commands  

**Question Text:**
```
True or False: AutoCAD uses vector-based graphics, not raster-based graphics.
```

**Correct Answer:** True

**Explanation:**
AutoCAD is primarily a vector-based CAD program, which means it uses mathematical equations to represent objects. This allows for precise scaling and editing without loss of quality, unlike raster graphics which are pixel-based.

## ✅ QUESTION 3: PICK LIST (Dropdown)

**Type:** PL - Pick List (Dropdown)  
**Points:** 8  
**Module:** Drawing Elements  

**Question Text:**
```
Which of the following is the primary tool used to create a rectangle in AutoCAD?
```

**Options:**
```
RECTANGLE
CIRCLE
LINE
POLYGON
ELLIPSE
```

**Correct Answer:** RECTANGLE

**Explanation:**
The RECTANGLE command creates a four-sided closed polyline with 90-degree corners. While you can create rectangles using other tools, RECTANGLE is the dedicated command for this purpose.

## ✅ QUESTION 4: ORDERED LIST (Ranking)

**Type:** OL - Ordered List (Ranking)  
**Points:** 12  
**Module:** Workflow  

**Question Text:**
```
Arrange these steps in the correct order for creating a professional technical drawing in AutoCAD:
```

**Items (in correct order):**
```
1. Set up the drawing with appropriate units and scale
2. Draw basic geometry using lines, circles, and rectangles
3. Add dimensions to your drawing
4. Apply constraints and ensure geometric accuracy
5. Add text notes and labels
6. Prepare the drawing for printing or export
```

**Correct Order:** 1 → 2 → 4 → 3 → 5 → 6

**Explanation:**
The proper workflow ensures that your foundation is set up correctly before drawing. Constraints should be applied before dimensions to maintain accuracy. Text and labels come after dimensions, and preparation for output is the final step.

## ✅ QUESTION 6: FREE TEXT / ESSAY

**Type:** EA - Essay  
**Points:** 15  
**Module:** Best Practices  

**Question Text:**
```
Explain the importance of using layers in AutoCAD drawings. Include at least 3 benefits of organizing objects into different layers. Write at least 100 words.
```

**Minimum Words:** 100  
**Maximum Words:** 500  

**Sample Good Answer:**
```
Layers are one of the most important organizational tools in AutoCAD. They allow designers to group related objects and control their visibility, color, and printing properties independently.

First, layers help organize complex drawings by separating different types of elements. For example, you might have separate layers for walls, doors, windows, and furniture. This makes it much easier to navigate large projects and find specific elements quickly.

Second, layers enable selective visibility. You can turn specific layers on or off to show or hide certain elements of the drawing. This is particularly useful when working with clients or colleagues, as you can present different versions of the same drawing highlighting different aspects.

Third, layers allow for different printing styles and line weights. You can assign different colors and line weights to different layers, and these properties are maintained when plotting the drawing to paper or PDF. This ensures professional-looking output with appropriate emphasis on important elements.

Additionally, layers facilitate collaboration, as different team members can work on different layers of the same drawing without interfering with each other's work.
```

**Explanation:**
The answer demonstrates:
- Understanding of layer purpose
- At least 3 clear benefits
- Professional explanation
- Sufficient detail and examples
- Proper word count (100-500)

## ✅ QUESTION 7: FILE UPLOAD / DATASET QUESTION

**Type:** FT - File Upload with Dataset  
**Points:** 20  
**Module:** Dataset Questions  

**Question Text:**
```
You are provided with an AutoCAD drawing file (sample.dwg) containing a floor plan. 

Tasks:
1. Identify all the rooms in the drawing
2. List the room names and their approximate dimensions
3. Explain the spatial relationship between rooms
4. Suggest one improvement to the layout

Upload your answer as a text file, Word document, or PDF.
```

**Allowed File Types:**
```
.txt
.pdf
.docx
.doc
```

**Sample Good Answer (as a text file):**
```
FLOOR PLAN ANALYSIS - Sample Drawing

ROOMS IDENTIFIED:
1. Living Room: approximately 20' x 15' (300 sq ft)
2. Kitchen: approximately 12' x 12' (144 sq ft)
3. Master Bedroom: approximately 15' x 14' (210 sq ft)
4. Second Bedroom: approximately 12' x 11' (132 sq ft)
5. Bathroom: approximately 8' x 6' (48 sq ft)
6. Hallway: approximately 3' x 20' (60 sq ft)

SPATIAL RELATIONSHIPS:
- The living room is centrally located and connects to the kitchen and hallway
- Bedrooms are positioned away from the main living areas
- The bathroom is conveniently located near the master bedroom
- The kitchen is adjacent to the living room for easy access

SUGGESTED IMPROVEMENT:
Consider adding a powder room or second bathroom near the living room area to reduce traffic flow to the master bathroom. This would improve functionality for guests and reduce congestion in the hallway.
```

**Explanation:**
The answer demonstrates:
- Careful analysis of the drawing
- Accurate measurements and identification
- Understanding of spatial planning
- Practical suggestions for improvement
- Clear, professional documentation
